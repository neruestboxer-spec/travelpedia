# Travelpedia — Sistem Manajemen Bisnis Travel

Frontend SPA (HTML/CSS/JS vanilla) untuk Travelpedia ERP. Backend: Google Apps Script Web App (Google Sheets + Drive + Gmail).

- Konfigurasi URL backend: `js/config.js` → `GAS_URL`
- Panduan lengkap: [PANDUAN-INSTALASI.md](PANDUAN-INSTALASI.md)

Modul: Dashboard · Customer · Booking (3 langkah) · Pembayaran DP/Pelunasan · Invoice/Kuitansi PDF · Jadwal Keberangkatan (kalender & daftar) · Trip & Harga · Supplier · Keuangan & Laba/Rugi · Transaksi Kas · Payroll & Slip Gaji · Karyawan · Pengguna · Pengaturan · Log Aktivitas.
